# 加密评分与信号规范（v1.3.0）

本文件是加密分支评分、方向和执行动作的唯一规范；可执行实现为
`generate_crypto_reports.py`。修改任一阈值时必须同步修改实现与测试。

## 1. 三个概念必须分开

| 概念 | 范围 | 回答的问题 |
|------|------|------------|
| 综合状态评分 | 0–100 | 市场处于低热度、平衡还是高热度状态？ |
| 方向评分 | -8–+8 | 四周期 RSI/MACD 更偏多还是偏空？ |
| 执行动作 | LONG/SHORT/HOLD/REDUCE | 当前是否允许建立或减少方向仓位？ |

综合状态评分不是上涨概率、策略胜率或自动交易指令。

## 2. 综合状态评分

```text
综合状态评分 = 宏观周期×0.30 + 量价动能×0.40 + 衍生品×0.30
```

### 2.1 宏观周期（30%）

BTC：

| AHR999 | 分数 |
|--------|------|
| <0.45 | 25 |
| 0.45–0.80 | 35 |
| 0.80–1.20 | 50 |
| 1.20–2.00 | 70 |
| ≥2.00 | 85 |

非 BTC：

```text
42
+ 0.12×(20日区间位置−50)
+ 8（价>EMA50）或 −3（价≤EMA50）
+ 7（价>EMA200）或 −4（价≤EMA200）
```

结果限制在 20–80。宏观低分表示周期位置较低，不等于立即买入。

### 2.2 量价动能（40%）

基础分 50。15m/1H/4H/1D 权重分别为 1/2/3/4：

- RSI>55：加对应周期权重；RSI<45：减对应周期权重。
- MACD 柱>0：加对应周期权重；MACD 柱<0：减对应周期权重。
- 价>MA20：+3，否则−3。
- 价>EMA50：+2，否则−2。
- KDJ J>90 或 J<20：−2，表示极端区动能可靠性下降。
- 结果限制在 20–80；未达到 RSI≥70 且 KDJ J<85 时，上限为72，避免把普通强势误标过热。

### 2.3 衍生品（30%）

基础分 50：

- 资金费率<0：+8。
- 资金费率>0.005%：−4。
- 顶级交易员多空比≥1.20：+10；1.05–1.20：+5。
- 顶级交易员多空比≤0.80：−10；0.80–0.95：−5。
- OI 单点只表示规模，没有变化方向，**不加减分**。
- 结果限制在 20–80。

### 2.4 状态区间

| 分数 | 状态 |
|------|------|
| 0–<20 | 深度价值区 |
| 20–<40 | 复苏区 |
| 40–<60 | 中性区 |
| 60–<80 | 过热区 |
| 80–100 | 狂热区 |

状态区间只描述市场状态；低分不能自动推出 BUY，高分不能自动推出 SELL。

## 3. 方向评分与一致性

对 15m/1H/4H/1D 的 RSI 和 MACD 各投一票，共8票：

- RSI>55 或 MACD柱>0：+1。
- RSI<45 或 MACD柱<0：−1。
- 其它：0。

方向评分为−8至+8。一致性比例为8票中与净方向相同的票数比例；它不是胜率。
一致性等级同时要求净方向强度：高=`同向≥75% 且 |方向分|≥6`；
中=`同向≥62% 且 |方向分|≥4`；其它为低，避免把4比3的微弱多数称为中高一致。

## 4. 执行动作门控

按以下顺序判定，先命中即停止：

1. **REDUCE 过热减仓（不做空）**：状态分≥60、价格≥EMA50，且4H/1D RSI≥70或KDJ J≥85。
2. **LONG 偏多确认**：方向分≥+5、量价分≥60、衍生品分≥50、价格≥EMA50，且未命中过热。
3. **SHORT 偏空确认**：方向分≤−5、量价分≤40、衍生品分≤45、价格<EMA50。
4. 其它全部 **HOLD**。

HOLD 的描述标签：

- 量价分≥58：`NEUTRAL 动能偏多`。
- 量价分≤35：`NEUTRAL 动能偏弱`。
- 其它：`NEUTRAL 动能分化`。

`动能偏多/偏弱`只是观察描述，不是开仓命令。

## 5. 报告硬约束

- 必须同时显示综合信号、执行动作、状态评分和方向评分。
- REDUCE 必须明确“不做空”；不得再写成 SELL。
- HOLD 只显示当前价格，不显示伪精确入场、止损、止盈。
- 一致性只能叫“一致性等级/指标同向比例”，不得称为胜率或概率。
- OI 没有历史序列时必须注明“单点快照，不计方向分”。
- 任一输入包含 `FETCH_FAILED` 时拒绝生成报告。
